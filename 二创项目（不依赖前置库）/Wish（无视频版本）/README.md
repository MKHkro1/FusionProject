# Wish (许愿池)

许愿池植物插件，基于 BepInEx 框架开发。

## 植物信息

- **植物ID**: 2000
- **植物类型**: GoldSunflower（金向日葵类）
- **花费**: 648 阳光
- **韧性**: 888
- **冷却**: 60 秒（卡槽冷却），技能无冷却
- **特点**: 彩卡

## 功能说明

### 抽卡功能

花费 **1600金钱** 进行抽卡，技能无冷却。

### 抽卡概率（初始）

- **80% 蓝卡**：惊喜礼盒卡片（256）【播放 bule 视频】
- **15% 紫卡**：随机超极植物卡片（1005/1013/1026/1046/1052/1066/1104/1110/1126/1148/1220/1234）【播放 purple 视频】
- **4% 金卡**：随机究极植物卡片（900-962）【播放 gold 视频】
- **1% 捕获明光**：惊喜礼盒卡片（256）+ 随机究极植物卡片（900-962），并消除一条僵尸词条或获得一条植物词条【播放 supergold 视频】

### 概率递增机制

每抽取一次，如果没出金卡或捕获明光，蓝卡将 **1%** 的概率分给紫卡和金卡（各 **0.5%**），以此类推，直到抽出了金卡或捕获明光，然后重置概率。

## 资源文件

AssetBundle 文件应命名为 `wish`（或 `wish.unity3d`、`wish.bundle`），包含以下资源：

- **Prefab**:
  - `WishPrefab`: 主要植物预制体
  - `WishPreview`: 预览预制体

- **视频文件（MP4）**:
  - `bule`: 蓝卡视频
  - `purple`: 紫卡视频
  - `gold`: 金卡视频
  - `supergold`: 捕获明光视频

- **动画**: `idle`（原有的动画）

## 安装说明

1. 将编译后的 DLL 文件放入游戏的 BepInEx 插件目录
2. 将 AssetBundle 文件（`wish`）放入以下任一位置：
   - `StreamingAssets/Mods/` 目录
   - 插件 DLL 同目录
3. 启动游戏，植物会自动注册

## 构建说明

使用 .NET 6.0 SDK 构建项目：

```bash
dotnet build -c Release
```

编译后的 DLL 位于 `bin/Release/net6.0/` 目录。

## 依赖项

- BepInEx (IL2CPP)
- CustomizeLib.BepInEx
- Harmony
- Il2CppInterop

## 注意事项

- 需要游戏版本 3.1.1
- 需要 CustomizeLib 前置库
- 词条操作需要 TravelMgr 已初始化
- 视频播放需要 Unity VideoModule 支持

## 开发说明

项目结构：
- `Core.cs`: 主代码文件，包含所有功能实现
- `Wish.BepInEx.csproj`: 项目配置文件
- `wish`: AssetBundle 资源文件（需要手动放置）

主要功能模块：
1. 植物注册和AssetBundle加载
2. 抽卡逻辑和概率系统（包括递增机制）
3. 视频播放功能
4. 卡片掉落和词条操作
5. 图鉴文本和彩卡支持
