# 纠缠之缘插件开发经验总结

## 问题背景

在开发过程中遇到的核心问题：**视频播放后无法正常清理，导致视频残留遮挡游戏画面**。

### 具体表现
1. 植物销毁后，视频卡在最后一帧无法清理
2. 退出游戏主界面后，视频仍然停留在画面上
3. 视频播放完成后，没有自动消失

## 问题根源分析

### 1. 视频清理依赖固定时长
- **问题**：初始实现使用固定7秒播放时长，如果植物在此期间被销毁，需要等待完整7秒才会触发清理
- **影响**：无法响应植物销毁事件，导致视频残留

### 2. 植物销毁事件未触发清理
- **问题**：植物销毁时没有主动通知视频清理模块
- **影响**：协程可能仍在运行但无法感知植物状态变化

### 3. CameraFarPlane 渲染模式特殊处理
- **问题**：使用 `VideoRenderMode.CameraFarPlane` 时，简单调用 `Destroy()` 无法完全清理视频帧
- **影响**：视频最后一帧会残留在相机远平面上

### 4. 协程与对象生命周期不同步
- **问题**：植物对象销毁后，协程可能仍在运行，访问已销毁对象会抛出异常
- **影响**：清理逻辑无法正常执行

## 解决方案

### 1. 添加 Plant.OnDestroy 补丁（核心解决方案）

**实现方式**：
```csharp
[HarmonyPatch(typeof(Plant), "OnDestroy")]
internal static class PlantOnDestroyPatch
{
    [HarmonyPostfix]
    private static void Postfix(Plant __instance)
    {
        // 只处理目标植物
        if (__instance is GoldSunflower goldSunflower && 
            goldSunflower.thePlantType == (PlantType)Core.PlantId)
        {
            // 1. 停止协程
            // 2. 清理所有视频（使用 forceImmediate: true）
            // 3. 移除概率状态
        }
    }
}
```

**关键点**：
- 使用 Harmony 补丁监听 Unity 的 `OnDestroy` 生命周期事件
- 在植物销毁的第一时间触发清理，不等待定时检查
- 使用 `forceImmediate: true` 强制立即销毁，避免延迟

### 2. 改进视频清理方法

**CleanupVideoObject 方法的关键步骤**：
```csharp
internal static void CleanupVideoObject(GameObject? videoObject, bool forceImmediate = false)
{
    // 1. 停止播放
    videoPlayer.Stop();
    
    // 2. 【关键】改变渲染模式，避免 CameraFarPlane 残留
    videoPlayer.renderMode = UnityEngine.Video.VideoRenderMode.MaterialOverride;
    
    // 3. 清除相机引用
    videoPlayer.targetCamera = null;
    
    // 4. 清空视频片段
    videoPlayer.clip = null;
    
    // 5. 禁用组件
    videoPlayer.enabled = false;
    
    // 6. 销毁 VideoPlayer 组件
    UnityEngine.Object.Destroy(videoPlayer);
    
    // 7. 销毁 GameObject
    if (forceImmediate)
        UnityEngine.Object.DestroyImmediate(videoObject);
    else
        UnityEngine.Object.Destroy(videoObject);
}
```

**关键点**：
- **必须先改变渲染模式**：从 `CameraFarPlane` 改为 `MaterialOverride`，才能彻底清理
- 清理顺序很重要：先停止、改变模式、清除引用，再销毁组件
- `forceImmediate` 用于场景切换等关键时刻，立即销毁避免残留

### 3. 多层清理机制

建立了**四层保护机制**，确保视频在各种情况下都能被清理：

#### 第一层：实时检测（视频播放循环中）
```csharp
while (elapsed < videoPlayDuration)
{
    // 每帧检查植物是否有效
    bool plantValid = false;
    try
    {
        plantValid = plant != null && IsPlantValid(plant);
    }
    catch
    {
        plantValid = false; // 访问异常说明植物已销毁
    }
    
    if (!plantValid)
    {
        CleanupVideoObject(videoObject);
        yield break; // 立即退出协程
    }
    
    elapsed += Time.deltaTime;
    yield return null;
}
```

#### 第二层：OnDestroy 事件（植物销毁时）
- 使用 Harmony 补丁监听 `Plant.OnDestroy`
- 立即清理相关资源，使用 `forceImmediate: true`

#### 第三层：定期清理（Board.Update 中）
```csharp
[HarmonyPatch(typeof(Board), "Update")]
internal static class BoardUpdatePatch
{
    // 每10秒清理一次
    // 检查植物是否已销毁，清理对应的协程和视频
}
```

#### 第四层：场景切换清理
```csharp
// 监听场景切换事件
SceneManager.activeSceneChanged += OnSceneChanged;
SceneManager.sceneUnloaded += OnSceneUnloaded;

private static void OnSceneChanged(Scene oldScene, Scene newScene)
{
    StopAllVideosAndCoroutines();
}
```

### 4. 异常处理与性能优化

#### 异常处理
- 使用 `try-catch` 包裹植物有效性检查，避免访问已销毁对象时崩溃
- 在清理方法中使用多重异常保护，确保即使部分步骤失败也能继续执行

#### 性能优化
- 使用 `HashSet<GameObject>` 存储活动视频，快速查找和移除
- 定期清理使用帧跳过（每60帧检查一次），减少 `Time.time` 调用
- 批量处理清理操作，减少 GC 压力

## 关键技术点总结

### 1. Unity 视频播放清理要点
- **CameraFarPlane 模式特殊处理**：必须先改变渲染模式才能彻底清理
- **清理顺序**：Stop → Change RenderMode → Clear References → Destroy Component → Destroy GameObject
- **立即销毁时机**：场景切换、对象销毁时使用 `DestroyImmediate`

### 2. Harmony 补丁使用
- 使用 `[HarmonyPatch]` 监听 Unity 生命周期事件（如 `OnDestroy`）
- 可以访问 `__instance` 获取被补丁的对象实例
- 使用 `[HarmonyPostfix]` 在原方法执行后执行清理逻辑

### 3. 协程与对象生命周期管理
- 使用 `Dictionary<Plant, Coroutine>` 跟踪活动协程
- 使用 `HashSet<GameObject>` 跟踪活动视频对象
- 在对象销毁时主动清理关联资源

### 4. 多层防护机制
- **实时检测**：在关键循环中每帧检查
- **事件驱动**：使用生命周期事件立即响应
- **定期清理**：作为后备机制定期检查
- **场景切换**：全局清理确保无残留

## 最佳实践建议

### 1. 视频播放相关
- ✅ 总是使用多层清理机制
- ✅ 使用 `OnDestroy` 补丁作为主要清理入口
- ✅ 处理 `CameraFarPlane` 渲染模式时，必须先改变模式
- ✅ 在关键时刻使用 `DestroyImmediate` 而非 `Destroy`
- ❌ 不要只依赖固定时长的延迟清理
- ❌ 不要忽略渲染模式的清理顺序

### 2. 资源管理
- ✅ 使用集合（Dictionary/HashSet）跟踪活动资源
- ✅ 提供统一的清理方法，确保清理逻辑一致
- ✅ 在清理方法中使用多重异常保护
- ❌ 不要直接销毁对象而不清理关联资源

### 3. 性能优化
- ✅ 使用帧跳过减少频繁检查
- ✅ 批量处理清理操作
- ✅ 使用快速数据结构（HashSet）进行查找
- ❌ 避免在 Update 中每帧执行重量级操作

### 4. 调试建议
- ✅ 添加详细的日志输出，方便追踪清理过程
- ✅ 在关键清理点输出日志（如："检测到植物销毁事件"）
- ✅ 记录清理的对象数量（如："清理 X 个视频"）
- ❌ 不要在生产环境保留过多的 Debug 日志

## 总结

本次开发中最关键的收获是：

1. **事件驱动的清理优于定时检查**：`OnDestroy` 补丁能够在对象销毁的第一时间触发清理，比等待定时检查更可靠

2. **Unity 视频渲染模式需要特殊处理**：`CameraFarPlane` 模式下的视频清理需要先改变渲染模式，否则会残留

3. **多层防护机制的重要性**：单一清理机制可能失效，多层机制能够互相补充，确保资源被正确清理

4. **异常处理与性能优化并重**：既要保证功能正确性（异常处理），也要考虑性能影响（帧跳过、批量处理）

通过以上方案，成功解决了视频残留问题，确保游戏体验不受影响。
