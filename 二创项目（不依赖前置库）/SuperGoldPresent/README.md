# SuperGoldPresent (贪欲盒子)

贪欲盒子植物插件，基于 BepInEx 框架开发。

## 植物信息

- **植物ID**: 1732
- **植物类型**: Present（礼盒类）
- **花费**: 200 阳光
- **冷却**: 15 秒
- **特点**: 彩卡，可多次选取；可在水路和陆地种植

## 功能说明

### 陆地放置时

- **55%** 生成普通僵尸（ID: 0-125），击败可获得一张惊喜礼盒卡片（植物ID：256）
- **25%** 生成超级僵尸（ID: 200-211/213-217），击败可掉落一张随机超极植物卡片（植物ID：1005/1013/1026/1046/1052/1066/1104/1110/1126/1148/1220/1234）
- **15%** 生成究极僵尸（ID: 225/227/230/233/235-239/300-335），击败可掉落一张随机究极植物卡片（植物ID：900-962）
- **5%** 生成特殊僵尸（ID: 212/218-224/226/228-229/231-232/234），击败可掉落一张惊喜礼盒卡片（植物ID：256）和一张随机究极植物卡片（植物ID：900-962），并且随机消除一条已生效的僵尸词条，如果没有则获得一条随机植物词条

### 水路放置时

- **80%** 生成水路僵尸（ID: 11-13），击败可获得一张惊喜礼盒卡片（植物ID：256）
- **15%** 生成究极僵尸（ID: 239/310-314），击败可掉落一张随机究极植物卡片（植物ID：900-962）
- **5%** 生成特殊僵尸（ID: 234），击败可掉落一张惊喜礼盒卡片（植物ID：256）和一张随机究极植物卡片（植物ID：900-962），并且随机消除一条已生效的僵尸词条，如果没有则获得一条随机植物词条

## 资源文件

AssetBundle 文件应命名为 `supergoldpresent`（或 `supergoldpresent.unity3d`、`supergoldpresent.bundle`），包含以下 Prefab：

- `SuperGoldPresentPrefab`: 主要植物预制体
- `SuperGoldPresentPreview`: 预览预制体
- 动画：`idle`、`idleAlmanac`

## 安装说明

1. 将编译后的 DLL 文件放入游戏的 BepInEx 插件目录
2. 将 AssetBundle 文件（`supergoldpresent`）放入以下任一位置：
   - `StreamingAssets/Mods/` 目录
   - 插件 DLL 同目录
3. 启动游戏，植物会自动注册

## 构建说明

使用 .NET 6.0 SDK 构建项目：

```bash
dotnet build -c Release
```

编译后的 DLL 位于 `bin/Release/net6.0/` 目录。

## 依赖项

- BepInEx (IL2CPP)
- CustomizeLib.BepInEx
- Harmony
- Il2CppInterop

## 注意事项

- 需要游戏版本 3.1.1
- 需要 CustomizeLib 前置库
- 词条操作需要 TravelMgr 已初始化
